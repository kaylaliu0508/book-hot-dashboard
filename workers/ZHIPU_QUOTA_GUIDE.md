## 顺便：要不要把 key 也搬到 Workers？

**当前**：智谱 key 直接写在前端 `index.html` 里，公开仓库可见。
**问题**：跟聚美智数 secret 一样，会被人盯上偷刷。
**两种处理**：
- **A 简单版**：智谱 key 由于本身有计费保护（充多少花多少），**短期可以接受写在前端**。被盗最多每天损失几十块。
- **B 安全版**：把智谱 key 一起塞进 Cloudflare Worker，前端调 Worker、Worker 转发到智谱（同聚美智数那套架构）。

**建议**：等你部署完聚美智数 Workers 拿到 URL 后，我把**两个 key 都搬到同一个 Worker**，前端只剩 DeepSeek key。

## 备选方案（如果不想充智谱钱）

加一个豆瓣读书页面爬虫到 Workers 里：
```js
fetch(`https://book.douban.com/isbn/${ISBN}/`)
```
- 优势：免费、有简介+目录、有评分评论
- 劣势：需要在 Worker 加 User-Agent 反爬绕过，豆瓣会限流（每个 IP 几十次/天）
- 适合 ISBN 查询频率低的场景

如果你想走这条路，告诉我，我加进 isbn-proxy.js。
